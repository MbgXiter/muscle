# 💪 Roblox Muscle Legends - Cyberpunk Edition

Game Roblox dengan tema cyberpunk dengan fitur:
- 🏋️ Sistem Latihan Lengkap
- 🐛 Pet Glitch & Pukul Batu
- 📊 Stats System
- ✨ UI Neon Glow Cyberpunk
- 💾 Data Persistence

## 📁 Struktur Folder

```
/src
  /ServerScripts
    - PlayerManager.lua (Manage player data & stats)
    - ExerciseSystem.lua (Workout mechanics)
    - PetSystem.lua (Pet logic & damage)
    - DataSaveSystem.lua (DataStore)
    - LeaderboardSystem.lua (Ranking)
  
  /ClientScripts
    - MainUI.lua (Cyberpunk UI)
    - ExerciseUI.lua (Workout interface)
    - StatsDisplay.lua (Real-time stats)
    - PetUI.lua (Pet system UI)
    - CyberpunkEffects.lua (Neon glow effects)
  
  /Modules
    - Config.lua (Settings & balancing)
    - Utilities.lua (Helper functions)
    - CyberpunkTheme.lua (UI colors & styling)

/setup.md (Panduan instalasi)
```

## 🎮 Fitur Utama

### 1. Sistem Latihan
- Dumbbell Training (Meningkatkan Strength)
- Running (Meningkatkan Speed)
- Push-ups (Meningkatkan Endurance)
- Meditation (Meningkatkan Focus)

### 2. Pet System
- Glitch Pet (Mengikuti player & memberi buff)
- Stone Punch (Pukul batu untuk XP)
- Pet Evolution

### 3. Stats
- Strength (Kekuatan)
- Speed (Kecepatan)
- Endurance (Daya Tahan)
- Focus (Fokus)
- Level & Experience

### 4. UI Cyberpunk
- Neon Glow Effects
- Holographic Interface
- Dark Theme dengan Cyan/Purple Accent
- Animated Transitions
